## 4. What the Software does to your computer

You understand and agree that, when you start the relevant features:

- **Exam mode** installs a Windows low-level keyboard hook that blocks task-switching keys (such as Alt+Tab, the Windows key and Alt+F4) until the session ends. Keystrokes are not recorded or transmitted.
- **Site blocking in exam mode** writes entries to the Windows hosts file after you approve a Windows administrator prompt. A backup is made first. If the Software is force-quit or crashes, the entries may remain until you reopen the Software or use Settings → RESET HOSTS FILE NOW.
- **The optional camera view** uses your webcam only after you turn it on and Windows grants permission. Video is not recorded, stored or transmitted.
- **The emergency exit, Ctrl+Shift+Q,** closes the Software immediately in every mode.

Keep backups of important data. Do not use the Software on computers you are not authorised to modify, such as school, exam-centre or employer machines, without the owner's permission.
